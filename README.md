# Cardápio Digital AçaíDicasa

Este é um cardápio digital moderno e automatizado para o AçaíDicasa, desenvolvido em HTML, CSS e JavaScript.

## Funcionalidades

- **Seleção de Funcionária**: O cliente pode selecionar a funcionária que está o atendendo, com emojis representativos.
- **Cardápio de Açaí**: Diferentes tamanhos de açaí com preços e limites de acompanhamentos e caldas.
- **Cardápio de Sorvete**: Opções de sorvete em diversos tamanhos.
- **Sistema de Acompanhamentos**: Seleção de acompanhamentos com limite baseado no tamanho do açaí.
- **Sistema de Caldas**: Seleção de caldas com limite baseado no tamanho do açaí.
- **Resumo do Pedido**: Visualização em tempo real do pedido e cálculo automático do total.
- **Opções de Consumo**: Escolha entre consumo no local ou para viagem.
- **Envio via WhatsApp**: Envio automático do pedido formatado para o WhatsApp.
